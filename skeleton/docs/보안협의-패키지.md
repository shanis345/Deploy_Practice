# 보안 협의 패키지 — 에이전트 파일럿

## 1. 데이터 흐름도
    사용자 PC ──(1)──▶ [DMZ] 게이트웨이 ──(2)──▶ [업무망] 에이전트 ──(3)──▶ [DB존] DB (조회 전용)
                                                        │──(4)──▶ [업무망] ERP API
                                                        └──────▶ [업무망] LLM 게이트웨이 ──(5)──▶ 사내 프록시 ──▶ 외부 LLM (FQDN 1개)
                                                                          └──▶ [관리망] 감사 로그 DB (7)
## 2. 외부 전송 데이터
- 전송 주체: LLM 게이트웨이만 (에이전트는 인터넷 경로 없음 — NetworkPolicy/네트워크 분리로 강제, verify.sh #3)
- 전송 내용: 사용자 질문 + 시스템 프롬프트 + 조회 결과 요약. 개인정보 필드는 마스킹 후 전송 (마스킹 규칙 별첨)
- 목적지: `<llm-endpoint>:443` 1개. 제공사 데이터 미보관(ZDR) 계약 여부: (기재)
- 국외 이전 여부: (기재) — 개인정보 포함 시 국외이전 동의·고지 검토
## 3. 기록
- 감사 로그: 호출자(가상 키)·시각·모델·토큰·비용·성공 여부. 보관 1년(제안). 프롬프트 원문은 (보관 안 함 / 해시만 / 암호화 보관) 중 합의
- 애플리케이션 로그: JSON Lines, 개인정보·원문 미포함, 사내 로그 시스템으로 전송
## 4. 통제
- 이미지: non-root, 취약점 CRITICAL 0 (리포트 첨부), SBOM 첨부, 비밀 미포함
- 접근: DB 조회 전용 계정, 게이트웨이 키 기반 인증, 사용자 인증은 정식 전환 시 SSO
- 네트워크: 존 분리 + 방향성 정책, 화이트리스트 프록시, 아웃바운드 1개
## 5. 회수
- 파일럿 종료 시: 방화벽 정책 회수, 가상 키 폐기, 감사 로그 보관 이관, 이미지·볼륨 삭제 확인서
