사용자 붙여넣기에서는 jq 식 뒤의 따옴표가 중복됨. 정확한 실행 문자열은 별도 확인하지 않음.

$ curl -s -X POST localhost:8000/ask -H 'Content-Type: application/json' -d '{"question":"안녕"}'
{
  "answer": "(echo) 안녕",
  "mode": "offline",
  "prompt_sha": "e3b0c44298fc"
}

실행 사용자 확인 출력:
uid=10001(appuser) gid=0(root) groups=0(root)
사용자 붙여넣기 명령은 docker exec agent idd로 표기됨.
가이드의 정상 명령은 docker exec agent id이며 제공 출력은 그 예상 결과와 일치함.

$ docker rm -f agent
agent
이후 Ubuntu 셸 프롬프트로 복귀.
