Day 2 사용자 제공 Ubuntu 출력 — 주요 증거 발췌
실습일: 2026-09-24 / 정리일: 2026-09-25
출처: 사용자가 대화에 붙여넣은 실행 결과. Codex 직접 실행 로그가 아님.
구성: 실제 출력의 주요 행을 절별로 발췌했다. 전체 터미널 덤프가 아니며
생략한 행이나 예상 출력을 새 실행 결과로 추가하지 않았다.

[2-1 빈 네임스페이스]
$ sudo ip netns exec biz ip -brief addr
lo               DOWN
$ sudo ip netns exec biz ping -c1 -W1 8.8.8.8; echo "종료코드=$?"
ping: connect: Network is unreachable
종료코드=2

[2-4 사전 값·설정·TCP 성공]
$ sysctl net.ipv4.ip_forward
net.ipv4.ip_forward = 0
$ sudo iptables -S FORWARD
sudo: iptables: command not found

후속 설치 안내 뒤 사용자 출력:
$ iptables --version
iptables v1.8.10 (nf_tables)
$ sudo iptables -S FORWARD
-P FORWARD ACCEPT
$ sudo iptables -t nat -S POSTROUTING

$ sudo sysctl -w net.ipv4.ip_forward=1
net.ipv4.ip_forward = 1
$ sudo iptables -t nat -S POSTROUTING
-P POSTROUTING ACCEPT
-A POSTROUTING -s 10.42.0.0/24 ! -o br-lab -j MASQUERADE
$ sudo ip netns exec biz nc -zv -w3 1.1.1.1 443
